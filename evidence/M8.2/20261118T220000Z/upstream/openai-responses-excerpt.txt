for await (const event of stream) {
  if (
    event.type === "response.output_item.added" &&
    event.item.type === "function_call"
  ) {
    finalToolCalls[event.output_index] = event.item;
  } else if (event.type === "response.function_call_arguments.delta") {
    const index = event.output_index;

    if (finalToolCalls[index]) {
      finalToolCalls[index].arguments += event.delta;
    }
  }
}

=== Chat Completions streaming (chat.completion.chunk) ===
Source: OpenAI API reference / docs guide (and repo fixture test/fixtures/mockllm/openai.go
which mirrors it). Wire shape: each SSE frame is `data: <chat.completion.chunk JSON>` and the
stream ends with `data: [DONE]`. A chunk carries choices[].delta with optional
tool_calls[] entries; each entry has {index, id?, type?, function:{name?, arguments?}};
the first delta for an index carries id+name and subsequent deltas carry argument
fragments. The call list ends when a chunk's choice has finish_reason "tool_calls"
(or "stop"). Multiple calls may interleave by index.
Example chunk:
